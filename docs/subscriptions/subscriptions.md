# Subscription Logic

## DEFAULT
- Buy (with valid card/with invalid card/Insufficient funds)
- Change (Upgrade/Downgrade)
- AUTOMATIC RENEWAL
- Dunning (?)
- CANCEL

## PREPAID
- Buy (pre-purchase) (with valid card/with invalid card/Insufficient funds)
- Test sub available after registration on app
- Change (Upgrade/Downgrade)
- AUTOMATIC RENEWAL
- Dunning (?)
- CANCEL

## PAID_EXTERNALLY (Axa, Europass)
- Test sub available after registration on app
- AUTOMATIC RENEWAL
- Dunning (not to user but to insurance?)
- CANCEL
